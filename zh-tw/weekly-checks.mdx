## 檢查清單

- [ ] 檢查輪胎胎壓，並查看是否有任何刺穿或漏氣
- [ ] 檢查輪胎胎紋深度和磨損情況
- [ ] 測試前後煞車是否正常運作
- [ ] 檢查煞車油液位（如適用）
- [ ] 測試前燈、煞車燈和方向燈
- [ ] 更換任何燒壞的燈泡
- [ ] 檢查引擎機油液位，並在需要時補充
- [ ] 檢查車輛是否有機油洩漏
- [ ] 檢查鏈條或皮帶是否磨損或鬆弛
- [ ] 如有需要，潤滑鏈條
- [ ] 檢查電池端子和連接情況
