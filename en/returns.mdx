## Return your vehicle

Return your vehicle as agreed at the end of your rental period. If you need to change the return location or timing, arrange it with Motion Rental before your return date or original return time.

<Callout kind="info" collapsed="false">
  If you want to return the vehicle to a different location than your pickup point, Motion Rental can often arrange this within the service area. A fee may apply.
</Callout>

### Before you return

Check the vehicle and everything that came with it before you hand it back. This helps avoid delays during inspection and reduces the chance of extra charges for missing items.

- Remove all personal belongings from the vehicle.

- Return any extras included with your rental, such as a helmet, food delivery bag, charger, or lock.

- Make sure the vehicle is in reasonable condition when you return it.

<Callout kind="alert" collapsed="false">
  If accessories are missing or returned damaged, additional charges may apply.
</Callout>

### Returning outside business hours

Do not leave the vehicle unattended unless Motion Rental has confirmed the return process with you. Outside business hours, contact Motion Rental first so they can tell you where and how to leave the vehicle safely.

### After the return

Once Motion Rental receives the vehicle, the team inspects it and finalises any outstanding items linked to your rental. This review may include fuel, tolls, damage, fines, or missing accessories.

If a Security Bond refund is due, Motion Rental handles that separately through the refund process.

## If you cannot return on time

Contact Motion Rental as soon as you know you may be late. Extensions depend on vehicle availability and must be approved before your original return time.

If you need to return the vehicle to another location, ask before your return date so the team can confirm whether that option is available.

<Callout kind="info" collapsed="false">
  Early communication matters. Contacting Motion Rental before your scheduled return gives the team the best chance to approve an extension or alternative return location.
</Callout>

## FAQs

<ExpandableGroup>
  <Expandable title="Can I return the vehicle to a different location?" default-open="false">
    Yes, this is generally possible within Motion Rental's service area if you arrange it in advance. A relocation fee may apply.
  </Expandable>

  <Expandable title="Can I extend my rental if I am running late?" default-open="false">
    You can request an extension, but Motion Rental must approve it before your original return time. Approval depends on availability.
  </Expandable>

  <Expandable title="What should I remove before returning the vehicle?" default-open="false">
    Remove all personal belongings and return any extras that came with the rental, including items such as a helmet, food delivery bag, charger, or lock.
  </Expandable>

  <Expandable title="Can I leave the vehicle after hours?" default-open="false">
    Only if Motion Rental has told you exactly how and where to return it. Do not leave the vehicle unattended without confirmation from the team.
  </Expandable>

  <Expandable title="What happens after I return the vehicle?" default-open="false">
    Motion Rental inspects the vehicle and checks for any outstanding rental items such as fuel, tolls, damage, fines, or missing accessories. Any Security Bond refund is handled separately.
  </Expandable>

  <Expandable title="Who should I contact if I cannot return as planned?" default-open="false">
    Contact Motion Rental directly before your scheduled return time. Reach out as soon as possible if you expect a delay, need an extension, or want to change the return location.
  </Expandable>
</ExpandableGroup>
